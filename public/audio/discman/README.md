# Músicas do Discman

Coloque aqui arquivos de áudio que você tenha autorização para usar e distribuir no portfólio público.

Primeira faixa: `01-cpm22-dias-atras.mp3` (CPM 22 — Dias Atrás). O arquivo não está incluído.

As outras quatro posições estão reservadas em `playlist.json`. Para adicionar cada música, preencha `title` e `file` com o nome do MP3 nesta pasta. Exemplo: `{"title":"Artista - Música","file":"02-minha-musica.mp3"}`.

O player informa quando o áudio ainda não está disponível, sem simular reprodução.
